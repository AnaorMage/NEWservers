🖥️ Система учета и расчета мощностей IT-инфраструктуры

Десктопное приложение для инвентаризации серверов, автоматического расчета доступных мощностей, привязки оборудования к информационным системам (ИС) и бизнес-потребностям, а также анализа инфраструктуры с помощью встроенного ИИ.

⚡ БЫСТРЫЙ СТАРТ НА НОВОМ НОУТБУКЕ (БЕЗ PYTHON)

Если на компьютере установлен только PostgreSQL / pgAdmin, устанавливать Python и дополнительные библиотеки НЕ НУЖНО. Программа запускается напрямую через готовый исполняемый файл.

Шаг 1. Скачивание проекта с GitHub

Нажмите зеленую кнопку «Code» в верхней части страницы репозитория.

Выберите пункт «Download ZIP» и дождитесь загрузки архива.

Распакуйте скачанный архив в любую удобную папку (например, на «Рабочий стол»).

Шаг 2. Развертывание базы данных через pgAdmin

Запустите программу pgAdmin 4 и введите мастер-пароль для входа.

Подключитесь к вашему серверу PostgreSQL в дереве слева.

Создайте базу данных:

Нажмите правой кнопкой мыши по «Databases» $\rightarrow$ «Create» $\rightarrow$ «Database...».

В поле «Database» введите строго имя: SERVERS

Нажмите кнопку «Save».

Откройте редактор SQL-запросов:

Кликните левой кнопкой мыши по созданной базе SERVERS, чтобы выбрать её.

В верхнем меню нажмите «Tools» $\rightarrow$ «Query Tool».

Примените структуру таблиц:

В распакованной папке проекта откройте файл schema.sql через стандартный «Блокнот».

Выделите весь текст (Ctrl + A) и скопируйте его (Ctrl + C).

Вставьте скопированный скрипт в окно Query Tool в pgAdmin (Ctrl + V).

Нажмите кнопку запуска «Execute» (иконка ▶ или клавиша F5).

Убедитесь, что снизу во вкладке Messages появилась надпись: Query returned successfully.

Шаг 3. Настройка файла конфигурации config.ini

Перейдите в распакованную папку проекта.

Скопируйте файл config.ini из корня проекта внутрь папки dist (положите его прямо рядом с файлом gui.exe).

Откройте файл dist/config.ini через «Блокнот».

Укажите ваш реальный пароль от PostgreSQL на этом ноутбуке в строке password:

[database]
host = 127.0.0.1
port = 5432
dbname = SERVERS
user = postgres
password = ВАШ_ПАРОЛЬ_ОТ_POSTGRES_НА_ЭТОМ_НОУТЕ

[ai]
ollama_url = http://127.0.0.1:11434/api/generate
ollama_model = qwen2.5:1.5b


Обязательно сохраните файл (Ctrl + S).

Шаг 4. Запуск программы

Зайдите в папку dist.

Запустите файл gui.exe двойным кликом мыши.

Приложение сразу откроет графическое окно со списком серверов, аналитикой и справочниками!

🤖 ИИ-ПОМОЩНИК (ОПЦИОНАЛЬНО)

Базовая диагностика рисков: проверка формата IP, дубликатов адресов, серверов старше 6 лет и нехватки памяти работает сразу из коробки без дополнительного ПО.

Развернутые текстовые рекомендации сисадмина: если вы хотите подключить локальную нейросеть, установите утилиту Ollama и выполните в командной строке:

ollama run qwen2.5:1.5b


🛠️ ЗАПУСК ИЗ ИСХОДНОГО КОДА (ДЛЯ РАЗРАБОТЧИКОВ)

Если на компьютере установлен Python 3.10+ и вы хотите запустить проект напрямую через консоль:

# 1. Клонирование репозитория
git clone https://github.com/AnaorMage/NEWservers.git
cd NEWservers

# 2. Создание и активация виртуального окружения
python -m venv venv
venv\Scripts\activate

# 3. Установка библиотек
pip install -r requirements.txt

# 4. Запуск приложения в оконном режиме
python gui.py
