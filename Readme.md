🖥️ Система учета и расчета мощностей IT-инфраструктурыДесктопное приложение для инвентаризации серверов, расчета вычислительных мощностей, привязки оборудования к информационным системам (ИС) и потребностям бизнеса, а также анализа инфраструктуры с помощью встроенного ИИ.⚡ Быстрый старт на новом компьютере (без Python)Если на компьютере установлен только PostgreSQL / pgAdmin, для запуска программы не требуется устанавливать Python или сторонние библиотеки.Шаг 1. Скачайте проект с GitHubНажмите зеленую кнопку Code в верхней части страницы $\rightarrow$ выберите Download ZIP.Распакуйте скачанный архив в любую удобную папку (например, на «Рабочий стол»).Шаг 2. Разверните базу данных в pgAdminОткройте pgAdmin 4 и подключитесь к вашему серверу PostgreSQL.В левой панели нажмите правой кнопкой мыши по Databases $\rightarrow$ Create $\rightarrow$ Database....В поле Database укажите точное имя: SERVERS и нажмите Save.Кликните левой кнопкой мыши по созданной базе SERVERS, чтобы выделить её.В верхнем меню откройте Tools $\rightarrow$ Query Tool (откроется редактор SQL-запросов).В распакованной папке проекта откройте файл schema.sql через «Блокнот»:Выделите весь текст (Ctrl + A) и скопируйте (Ctrl + C).Вставьте запрос в окно редактора в pgAdmin (Ctrl + V).Нажмите кнопку Execute (иконка треугольника ▶ или клавиша F5).В нижней вкладке Messages появится сообщение об успешном выполнении — все таблицы и справочники созданы!Шаг 3. Настройте файл конфигурации config.iniСкопируйте файл config.ini из корня проекта в папку dist (прямо рядом с файлом gui.exe).Откройте dist/config.ini в любом текстовом редакторе (например, в «Блокноте»).В блоке [database] укажите ваш пароль от пользователя postgres на этом компьютере:[database]
host = 127.0.0.1
port = 5432
dbname = SERVERS
user = postgres
password = ВАШ_ПАРОЛЬ_ОТ_POSTGRES

[ai]
ollama_url = http://127.0.0.1:11434/api/generate
ollama_model = qwen2.5:1.5b
Сохраните изменения (Ctrl + S).Шаг 4. Запустите приложениеПерейдите в папку dist и запустите gui.exe двойным кликом мыши.Программа откроет графический интерфейс с таблицей серверов, статистикой и аналитикой.🤖 ИИ-помощник (опционально)В программу встроен системный аналитик:Базовая эвристическая диагностика (проверка формата IP, выявление дубликатов адресов, поиск серверов старше 6 лет, нехватка RAM/CPU) работает автоматически прямо из коробки.Генерация текстовых рекомендаций администратора: если вы хотите получать развернутые советы от локальной нейросети, установите утилиту Ollama и выполните в консоли:ollama run qwen2.5:1.5b
